# 陶瓷素胚加工工坊管理小程序 PRD

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品名称 | 陶瓷素胚加工工坊管理小程序 |
| 文档版本 | v0.1 |
| 目标用户 | 家庭陶瓷加工工坊经营者、记账人员、工序工人 |
| 核心目标 | 素胚进货有数，加工工序可配，工资自动算，烧制损耗看得见，订单利润算得清 |

## 2. 背景与问题

当前工坊主要业务不是从泥料开始制坯，而是从市场采购素胚，经过贴花、手绘、上釉、烧制、检品、包装等加工后再销售。

目前主要痛点包括：

- 人工记账容易漏记、错记，收入支出难以追踪。
- 订单信息分散，订单进度、交期、收款状态不清楚。
- 每个订单会经过多个工序，工序负责人、数量、工价和工资统计混乱。
- 素胚采购、使用、损耗和成品库存缺少统一记录。
- 烧制可能跨多个订单，烧制成本和损耗难以分摊。
- 工人工资依赖人工汇总，已结算和未结算不清楚。
- 很难快速知道每个订单到底赚了多少钱。

## 3. 产品定位

本产品是一个面向小型陶瓷素胚加工工坊的轻量级经营管理小程序。

第一版重点不是做复杂 ERP，而是解决家庭工坊最实际的几个问题：

- 订单不乱。
- 工序清楚。
- 库存有数。
- 工资自动算。
- 收支能记账。
- 利润能看见。

## 4. 用户角色

| 角色 | 说明 | 核心需求 |
| --- | --- | --- |
| 工坊负责人 | 管理订单、采购、生产进度、利润 | 看整体经营情况，知道订单进度和利润 |
| 记账人员 | 记录收入、支出、工资结算 | 快速记账，减少漏账 |
| 工序负责人 / 工人 | 负责具体加工工序 | 记录完成数量，确认工资 |
| 家庭成员管理员 | 协助查看、录入和核对数据 | 操作简单，数据清楚 |

## 5. 业务流程

核心流程：

```text
采购素胚
  -> 素胚入库
  -> 创建订单
  -> 订单占用 / 使用素胚
  -> 添加或套用自定义工序
  -> 工人完成工序并产生工资
  -> 烧制批次记录
  -> 检品并记录合格 / 瑕疵 / 损耗
  -> 包装 / 发货
  -> 收款
  -> 结算工资
  -> 查看订单利润
```

## 6. 核心功能范围

### 6.1 首页经营看板

首页用于快速了解工坊当前状态。

核心指标：

- 今日待办工序数量。
- 进行中订单数量。
- 临近交货订单数量。
- 本月收入。
- 本月支出。
- 本月预估利润。
- 未收款金额。
- 未结算工资。
- 素胚库存预警。

首页列表：

- 待处理订单。
- 快到交货期订单。
- 未完成工序。
- 未结清工资。
- 未收尾款订单。

### 6.2 订单管理

订单是系统主线。

订单字段：

| 字段 | 说明 |
| --- | --- |
| 订单编号 | 系统自动生成，可手动修改 |
| 客户 | 关联客户档案 |
| 产品名称 | 如杯子、盘子、碗、花瓶、摆件 |
| 数量 | 订单产品数量 |
| 单价 | 销售单价 |
| 总金额 | 数量 x 单价，可手动调整 |
| 下单日期 | 客户下单时间 |
| 交货日期 | 约定交付日期 |
| 订单状态 | 待加工、加工中、待烧制、待检品、待发货、已完成、已取消 |
| 收款状态 | 未收款、已收定金、部分收款、已结清 |
| 关联素胚 | 本订单使用的素胚类型和数量 |
| 备注 | 特殊要求、釉色、图案、包装要求等 |
| 图片 | 样品图、设计图、成品图、聊天截图等 |

订单详情页应展示：

- 基础订单信息。
- 关联客户。
- 使用素胚和成本。
- 工序进度。
- 工人工资合计。
- 烧制批次和损耗。
- 收款记录。
- 订单支出。
- 订单利润。

### 6.3 客户管理

客户字段：

- 客户名称。
- 联系人。
- 电话 / 微信。
- 地址。
- 客户类型：零售、批发、长期客户、临时客户。
- 历史订单。
- 欠款金额。
- 偏好备注，如常用器型、图案、釉色、包装要求。

核心能力：

- 创建订单时快速选择已有客户。
- 查看客户历史订单。
- 查看客户未结清金额。

### 6.4 素胚采购管理

记录从市场采购素胚的情况。

采购单字段：

| 字段 | 说明 |
| --- | --- |
| 采购单号 | 系统自动生成 |
| 供应商 | 素胚来源 |
| 采购日期 | 采购时间 |
| 素胚名称 | 如白瓷杯、盘子、碗 |
| 规格 | 尺寸、型号、容量等 |
| 采购数量 | 实际购买数量 |
| 单价 | 单个素胚成本 |
| 总价 | 采购数量 x 单价 |
| 入库数量 | 实际可用数量 |
| 破损数量 | 采购时发现破损 |
| 备注 | 市场、批次、质量说明等 |
| 图片 | 素胚图片、票据图片 |

核心能力：

- 采购后自动增加素胚库存。
- 记录采购支出。
- 支持查看某类素胚的采购历史和平均成本。

### 6.5 库存管理

第一版建议做轻量库存，重点管理素胚和成品。

库存类型：

- 素胚库存。
- 釉料 / 彩料 / 花纸。
- 包装材料。
- 成品库存。

素胚库存字段：

- 素胚名称。
- 规格。
- 当前库存。
- 平均成本。
- 最近采购价。
- 库存预警值。
- 备注。

库存变动类型：

- 采购入库。
- 订单使用出库。
- 破损报损。
- 盘点调整。
- 退货入库。

第一版重点：

- 订单使用素胚时扣减库存。
- 烧制或检品损耗时记录报损。
- 低库存提醒。

### 6.6 自定义工序管理

工序必须支持自定义，不能写死。

常见工序示例：

- 贴花。
- 手绘。
- 喷釉。
- 浸釉。
- 擦底。
- 装窑。
- 烧制。
- 出窑。
- 检品。
- 包装。
- 发货。

工序字段：

| 字段 | 说明 |
| --- | --- |
| 工序名称 | 用户自定义 |
| 排序 | 决定订单内工序顺序 |
| 负责人 / 工人 | 关联工人 |
| 加工数量 | 本工序处理数量 |
| 合格数量 | 工序完成后合格数量 |
| 损耗数量 | 破损或不合格数量 |
| 计价方式 | 按件、按批、按天、固定金额 |
| 工价 | 对应计价方式的单价 |
| 工资小计 | 系统自动计算，可手动调整 |
| 状态 | 未开始、进行中、已完成、返工、跳过 |
| 开始日期 | 可选 |
| 完成日期 | 可选 |
| 备注 | 特殊说明 |

工资计算规则：

```text
按件：工资 = 完成数量 x 单件工价
按批：工资 = 批次数 x 每批工价
按天：工资 = 天数 x 日工资
固定金额：工资 = 手动填写金额
```

### 6.7 工序模板 / 产品模板

为了减少重复录入，应支持模板。

产品模板字段：

- 模板名称，如贴花杯、手绘盘、定制花瓶。
- 默认素胚。
- 默认售价，可选。
- 默认工序列表。
- 每道工序的默认工价。
- 默认包装方式。
- 备注。

模板示例：

```text
模板：贴花杯
默认素胚：白瓷杯
默认工序：
1. 贴花：按件 0.8 元/个
2. 喷釉：按件 0.5 元/个
3. 装窑：按件 0.2 元/个
4. 烧制：按批 80 元/批
5. 检品：按件 0.1 元/个
6. 包装：按件 0.3 元/个
```

核心能力：

- 创建订单时可选择模板。
- 套用模板后可修改工序、工价、工人和数量。
- 模板工序支持新增、删除、排序。

### 6.8 烧制批次管理

烧制是该业务的重要环节，建议独立记录。

烧制批次字段：

| 字段 | 说明 |
| --- | --- |
| 批次编号 | 系统自动生成 |
| 烧制日期 | 入窑或出窑日期 |
| 窑炉编号 | 可选 |
| 关联订单 | 可关联一个或多个订单 |
| 产品数量 | 本批次烧制数量 |
| 烧制费用 | 电费、燃气费、外包烧制费等 |
| 合格数量 | 烧制成功数量 |
| 瑕疵数量 | 可降价销售数量 |
| 破损数量 | 报损数量 |
| 成本分摊方式 | 按数量分摊、按订单金额分摊、手动分摊 |
| 备注 | 温度、釉色效果、异常情况等 |

核心能力：

- 一个烧制批次可关联多个订单。
- 烧制成本可分摊到订单。
- 烧坏、瑕疵可同步影响订单和库存。

### 6.9 工人工资管理

工资主要由工序产生。

工人字段：

- 姓名。
- 联系方式。
- 常做工序。
- 默认工价，可选。
- 备注。

工资记录来源：

- 订单工序自动生成。
- 手动新增工资。
- 工资调整。

工资统计维度：

- 按工人。
- 按订单。
- 按工序。
- 按日期范围。
- 按结算状态。

工资状态：

- 未结算。
- 部分结算。
- 已结算。

工资结算字段：

- 结算单号。
- 工人。
- 结算周期。
- 工资明细。
- 应发金额。
- 调整金额。
- 实发金额。
- 结算日期。
- 支付方式。
- 备注 / 凭证图片。

### 6.10 记账管理

记账分收入和支出。

收入类型：

- 订单定金。
- 订单尾款。
- 零售收入。
- 批发收入。
- 其他收入。

支出类型：

- 素胚采购。
- 釉料 / 彩料 / 花纸。
- 工人工资。
- 烧制成本。
- 包装材料。
- 物流快递。
- 摊位 / 房租。
- 设备维修。
- 其他支出。

账目字段：

| 字段 | 说明 |
| --- | --- |
| 类型 | 收入 / 支出 |
| 分类 | 如订单收款、素胚采购、工资等 |
| 金额 | 收支金额 |
| 日期 | 发生日期 |
| 关联对象 | 可关联订单、采购单、烧制批次、工资结算单 |
| 经手人 | 记录人或付款人 |
| 支付方式 | 微信、支付宝、现金、银行卡等 |
| 备注 | 补充说明 |
| 凭证图片 | 转账截图、收据等 |

核心能力：

- 订单收款自动进入收入记录。
- 采购素胚自动生成支出记录。
- 工资结算自动生成支出记录。
- 支持手动记账。
- 支持按月查看收支汇总。

### 6.11 订单利润统计

每个订单应能自动计算利润。

订单利润公式：

```text
订单利润 =
订单收入
- 素胚成本
- 加工工资
- 烧制成本
- 包装物流
- 其他关联支出
```

订单利润页面展示：

- 订单总收入。
- 已收金额。
- 未收金额。
- 素胚成本。
- 工资成本。
- 烧制成本。
- 包装物流成本。
- 其他成本。
- 订单利润。
- 利润率。

注意事项：

- 素胚成本按订单实际使用数量计算。
- 烧制批次关联多个订单时，需要按规则分摊。
- 订单未结清时，利润应区分应收利润和实际到账利润。

### 6.12 提醒与待办

提醒类型：

- 订单快到交货期。
- 订单逾期未交付。
- 工序长时间未完成。
- 客户尾款未收。
- 工人工资未结算。
- 素胚库存低于预警值。
- 烧制批次有异常损耗。

第一版可先做站内提醒，后续再考虑微信订阅消息。

## 11. 非功能需求

### 11.1 易用性

- 操作流程要尽量短，适合家人日常使用。
- 常用字段提供默认值。
- 工序和工价尽量通过模板带出。
- 列表页突出待办、异常和未结事项。

### 11.2 数据准确性

- 工资、库存、利润等金额需要保留修改记录。
- 自动生成的账目应能追溯来源。
- 删除订单、工序、采购单前需要二次确认。

### 11.3 权限

MVP 可先做简单权限：

- 管理员：全部权限。
- 记账人员：订单、记账、工资查看和编辑。
- 工人：查看自己的工序和工资，可录入完成数量。

### 11.4 数据备份

- 支持云端存储。
- 后续支持 Excel 导出。
- 关键数据应避免误删。

- 多门店 / 多工坊。
- 条码或二维码扫码管理订单和库存。
- 图片识别票据金额。
- 月度经营报表。
- 客户对账单。
- 工人小程序端确认工资。

## 13. 成功指标

第一版上线后可以用以下指标判断是否有效：

- 订单是否都能在系统中查询到状态。
- 未收款订单是否明显减少遗漏。
- 工人工资是否能按月快速结算。
- 素胚库存是否能做到大致准确。
- 每个订单是否能看到基本利润。
- 家人是否愿意持续录入，而不是回到纸笔记账。

## 14. 待确认问题

以下问题会影响后续原型和数据结构设计：

- 工坊主要是按客户订单生产，还是也会先加工成品再零售？
- 一个订单通常只对应一种产品，还是会包含多个产品？
- 工人工资是否都按计件计算，是否存在日薪或临时工？
- 烧制是自家窑炉还是外包烧制？
- 烧制成本更适合按数量分摊，还是按订单金额分摊？
- 是否需要工人自己登录小程序填报完成数量？
- 家人更习惯手机录入，还是电脑后台录入？
- 是否需要支持打印或导出客户订单、工资单和对账单？
